# Барбершоп «Клинок» — онлайн-запись

Простое веб-приложение на React + Vite для онлайн-записи в барбершоп.
Все записи хранятся в `localStorage` браузера — без бэкенда и базы данных.

## Запуск

```bash
npm install
npm run dev
```

Затем откройте адрес, который выведет Vite в терминале (обычно `http://localhost:5173`).

## Страницы

- `/` — форма записи клиента: выбор услуги, даты, времени, имени и телефона.
- `/admin` — админ-панель со списком всех записей и кнопкой удаления.
- `/pricing` — тарифы Free / Pro, текущий тариф, демо-оплата и сброс на Free.

## Тарифы (DEMO PAYMENT)

- **Free — $0:** до 2 записей, услуги «Стрижка» и «Борода», запись на 7 дней вперёд.
- **Pro — $9.99/месяц:** без лимита записей, все услуги, запись на 14 дней, экспорт записей в PDF
  (кнопка в `/admin` открывает печать браузера → «Сохранить как PDF»).
- Оплата **демонстрационная**: реальных платежей нет, данные карты не запрашиваются.
  Тариф хранится в `localStorage` (ключ `barbershop_plan`) и сохраняется после перезагрузки.
  Сбросить на Free можно на странице `/pricing`.
- Логика тарифов и лимиты — в `src/plan.js`.

## Важно про localStorage

- Записи хранятся в браузере, в котором вы записывались/открывали `/admin`.
  Если открыть сайт в другом браузере или в режиме инкогнито — записей там не будет.
- Если очистить данные сайта в браузере, все записи удалятся.
- Занятые дата/время скрываются (зачёркиваются) для новых клиентов автоматически.

```
        ├── DateTimeStep.jsx

```

## Как изменить услуги или расписание

- Список услуг и цены — в `src/constants.js`, массив `SERVICES`.
- Часы работы и шаг слотов — там же, функция `generateTimeSlots` (сейчас 09:00–20:00 каждые 30 минут).
- Количество дней для записи вперёд — функция `generateAvailableDates` (сейчас 14 дней).
